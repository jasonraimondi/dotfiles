# herdr-app

The manual ships inside the binary and changes with each update. Load the current one before running any `herdr-app` command:

```sh
herdr-app --skill
```

Follow that manual for every `herdr-app` command. Starting, messaging, reading, or waiting on agents and programs belongs to herdr-core: use the herdr-core skill for those.
