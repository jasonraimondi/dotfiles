# herdr-core

The manual ships inside the binary and changes with each `hc update`. Load the current one before running any `hc` command:

```sh
hc --skill
```

Follow that manual for every `hc` command. It replaces the older `herdr` skill, whose commands do not apply to herdr-core. For changing what the person sees in the window, use the herdr-app skill.
